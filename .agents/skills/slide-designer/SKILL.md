# Slide Designer & Executive Presentation Skill

Comprehensive design standard and automation engine for crafting modern, high-impact, executive-level pitch decks and presentation slides.

---

## 1. Core Philosophy: Why Bad Slides Happen & How to Fix Them

Bad slides suffer from **"Document Syndrome"**—taking paragraphs from a report and pasting them into repetitive grey boxes with endless bullet points. 

### The Golden Rules of Executive Slide Design:
1. **Rule of One Core Takeaway (Action Headlines):**
   - A slide is an executive visual anchor, not a reading document.
   - Never use passive category titles alone (e.g. avoid just `"1. ปัญหา (Problem Statement)"`).
   - Use an **Action Title** that gives the key conclusion instantly (e.g. `"ปัญหาโรงอาหาร: ร้านค้าน้อย รอคิวปรุงอาหาร 5-10 นาทีช่วงพักเที่ยง"`), paired with a small category badge above (`PROBLEM & OPPORTUNITY`).
2. **Visual Hierarchy & Scannability (The 3-Second Test):**
   - The audience must grasp the slide's core message within 3 seconds.
   - Use bold anchor keywords at the beginning of each bullet or phrase.
   - Maximum 15–20 words per text block. Cut all academic filler.
3. **Diverse Layout Archetypes (Zero Monotony):**
   - Never repeat the same 3-vertical-cards layout across consecutive slides.
   - Match the layout archetype to the data type:
     - **Processes/Workflows:** Horizontal node flows with connecting chevrons (`01 -> 02 -> 03 -> 04`).
     - **Problems/Features:** Asymmetric Bento grids with high-contrast icon badges.
     - **Metrics/Financials:** Hero metric callout cards (huge numbers `32-44pt`) with sub-labels.
     - **Competitors:** Clean comparison matrix with clear check/cross visual badges.
     - **Business Model:** Native 9-box canvas drawn directly in PPTX (never a tiny blurry image!).
4. **Color Harmony & Surface Polish (60-30-10 Rule):**
   - **60% Dominant Canvas:** Clean crisp white (`#FFFFFF`) or subtle slate canvas (`#F8FAFC`).
   - **30% Structural Frame:** Dark slate text (`#0F172A`), soft borders (`#E2E8F0`), card containers (`#FFFFFF` with subtle shadows or contrasting header strips).
   - **10% Purposeful Accent:** Vibrant emerald (`#10B981`), royal blue (`#2563EB`), amber/coral (`#EA580C`), or violet (`#7C3AED`) used strictly to direct the eye to key focal points.

## 2. Typography Scale & Micro-Layouts

| Element | Font Size | Weight | Color Role | Purpose |
| :--- | :--- | :--- | :--- | :--- |
| **Category Badge** | 10–11 pt | Bold, Uppercase | Accent / Slate | Slide context chip |
| **Action Headline** | 22–26 pt | Bold | Primary Slate (`#0F172A`) | Main takeaway of the slide |
| **Hero Metric Number** | 32–44 pt | Extra Bold | Primary / Accent | High-impact numbers & stats |
| **Card / Box Title** | 14–16 pt | Bold | Dark Navy / Accent | Component header |
| **Body Text / Items** | 11–12 pt | Regular / Semibold | Slate (`#334155`) | Supporting scannable text |
| **Metric Label / Subtitle** | 9.5–10 pt | Medium | Muted Slate (`#64748B`) | Metric description |
| **Footer & Slide Counter** | 9–9.5 pt | Regular / Bold | Muted / Accent | Academic metadata & numbering |

*Recommended Fonts: `Leelawadee UI`, `Segoe UI`, `Inter`, `Prompt`, or `TH Sarabun New` (for strict formal university decks).*

## 3. Master Slide Layout Archetypes

### Archetype 1: Modern Cover / Title Slide
- Clean background with subtle brand accent bar.
- Category tag pill (e.g. `PITCH DECK | INNOVATIVE TECHNOPRENEURS`).
- High-impact Title (`36-40pt`) and Subtitle (`18-20pt`).
- Structured University / Team metadata card with 2 balanced columns and role badges.

### Archetype 2: Problem & Opportunity Matrix
- 3 distinct problem cards with colored status badges (`[CRITICAL]`, `[BOTTLENECK]`, `[INEFFICIENCY]`).
- Bottom callout banner: "Why this matters in our specific context" to ground the problem.

### Archetype 3: Solution Showcase & Value Proposition
- Split layout:
  - Left Column (40% width): Hero Solution Statement card with bold contrast, branding icon, and core promise.
  - Right Column (60% width): 3–4 modular capability cards with step badges, clear features, and tangible benefits.

### Archetype 4: Interactive Process Flow (How It Works)
- Horizontal 4-step linear flow (`01`, `02`, `03`, `04`).
- Step cards with numbered circle icons, connecting arrow markers, step name, and scannable bullets.

### Archetype 5: Customer Persona & Segmentation
- Side-by-side Persona Cards (e.g. End User Student vs Business Partner Merchant).
- Profile header with demographic chips (`Year 1-4`, `Peak Hours 11:30-13:00`).
- Two-column interior: "Daily Pains & Bottlenecks" vs "Desired Gains & Relief".

### Archetype 6: Value Proposition Canvas (VPC)
- 2 main panels: Customer Profile (Jobs, Pains, Gains) vs Value Map (Products/Services, Pain Relievers, Gain Creators).
- Visual color contrast: Amber/Coral for Pains, Emerald for Gains, Royal Blue for Features.

### Archetype 7: Native 9-Box Business Model Canvas (BMC)
- Rendered natively using PPTX rectangle shapes (NOT an embedded low-res image).
- Proper 5-column standard BMC structure with pastel category headers, clean 1pt borders, and scannable bullet points.

### Archetype 8: Competitive Advantage Matrix
- Clean comparison table: Features/Attributes vs Smart Queue vs Legacy Paper vs Delivery Apps.
- Clear visual badges: `✔ มีระบบ (Green)` vs `✖ ไม่มี (Muted Red)` vs `⚠ เสียค่าธรรมเนียมสูง (Amber)`.
- Highlight column with brand accent border for our solution.

### Archetype 9: 4Ps Marketing Mix (Bento Grid 2x2)
- 4 asymmetric or balanced Bento cards (`Product`, `Price`, `Place`, `Promotion`).
- Each card has a distinct colored header pill, bold sub-headers, and quantitative data.

### Archetype 10: Technical Architecture & System Flow
- 3-tier or 4-tier horizontal/vertical architecture cards (Frontend LIFF -> Cloud API Gateway -> Database & Logic -> Kitchen Display KDS).
- Clean directional flow arrows showing real-time data synchronization.

### Archetype 11: Financial Feasibility & Unit Economics
- Top: 3 Hero Metric KPI Cards (Revenue / OPEX / Break-Even Months) with giant numbers.
- Bottom: 2 detailed panels (Revenue Streams vs Cost Structure breakdown).

### Archetype 12: Roadmap, Risk Mitigation & Closing Vision
- 3-phase horizontal timeline milestones with time chips and status indicators.
- Executive Closing Slide with 3 Pillars of Impact and clear Call to Action (Next Steps).

## 4. Technical Implementation Rules (python-pptx)

1. **Widescreen 16:9 Standard:**
   ```python
   prs.slide_width = Inches(13.333)
   prs.slide_height = Inches(7.5)
   ```
2. **Safe Margins & Content Canvas:**
   - Left Margin: `Inches(0.8)`
   - Right Margin: `Inches(0.8)` (Total content width = `Inches(11.733)`)
   - Header Top: `Inches(0.4)`, Height: `Inches(0.95)`
   - Content Area Top: `Inches(1.50)`, Height: `Inches(5.30)`
   - Footer Top: `Inches(7.0)`, Height: `Inches(0.35)`
3. **Card Styling & Padding:**
   - Always set `tf.word_wrap = True` and explicit small margins (`margin_left=Inches(0.15)`, `margin_top=Inches(0.12)`).
   - Use clean 1pt solid borders (`card.line.color.rgb = CLR_BORDER`, `card.line.width = Pt(1)`).
   - Use distinct header strips or colored pill badges inside cards to structure content.
4. **Zero Overflow Protection:**
   - Calculate line counts and vertical space before rendering text.
   - For bullet points, set `space_before = Pt(3)` to `Pt(5)` and `space_after = Pt(0)`.
   - Never let text spill outside card boundaries or overlap with footers.

## 5. Speaker Notes Protocol

Every presentation slide MUST include structured Speaker Notes:
- **Time Target:** Explicit timing indicator (e.g. `[เวลา: 0:00 - 0:45 นาที]`).
- **Speaking Script:** Conversational, confident Thai script ready for the presenter to deliver.
- **Key Emphasis Points:** 2–3 bullet points highlighting what the presenter should emphasize or watch out for during Q&A.

## 6. Verification Protocol

Always execute visual verification after generating slides:
1. Compile PPTX with Python script.
2. Convert PPTX to PDF using LibreOffice headless (`soffice --headless --convert-to pdf`).
3. Render each slide to PNG using PyMuPDF (`pix = page.get_pixmap(dpi=150)`).
4. Inspect slides visually using `view_file` to confirm visual balance, typography, alignment, and zero occlusions.
